# UI Design Library

A React UI library.

The library is built on top of Radix UI primitives when possible.

Icons are a mix of Feather, Iconoir, and a few custom ones.

## Stack

- React
- TypeScript
- Vite
- Radix UI
- SCSS modules

## Scripts

```bash
pnpm install
pnpm dev
pnpm build
```

The dev server runs at http://localhost:5178.
